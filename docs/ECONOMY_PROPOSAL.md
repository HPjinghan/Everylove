## 0. 三层，一句话

| 层 | 管什么 | 单位 | 真钱？ |
| --- | --- | --- | --- |
| **亲密度** | TA 愿不愿意（分寸、秘密、主动性的档位） | 心动 / 羁绊值 / 温度 | 否，**不卖** |
| **商业化** | 他在不在、名场面有没有 | 订阅 + 按件 + 永久加槽 | 是 |
| **零钱** | 你们之间的钱：外卖、礼物、红包、请客 | ¥（拟真游戏币） | **永不挂钩** |

三条原则，贯穿全部数值：

1. **钱买不到爱**：真钱不涨亲密度，零钱也不涨亲密度。送礼 = 一次开口（+5，与卡片同口径），TA 的反应才是奖励。这是乙游的既有线（付费买剧情与陪伴，不买好感），也是「零劳动被爱」的前提。
2. **零钱永不售卖、不可提现、不随订阅变多**。这样它就不是「预付式支付手段」（日本資金決済法）、不是消耗型 SKU（窗口纪律）、也不会让免费层偷偷变好（红线 7）。它只是一层拟真：这部手机里有钱包，你们会互相花钱。
3. **等级决定 TA 愿不愿意，付费决定东西有没有**。名场面 = 两者都满足才成立。任何一边不能替代另一边。

## 1. 亲密度数值体系

> **2026-09-15 Harper 拍板，已落地 D-126**（本节保留作设计说明；数值以代码 `lib/bond.ts` 常量为准）：① 换联系方式前的心动涨幅交给模型判断 0–15，聊得不相关可以是 0，要符合人设；② 羁绊值来源要更多，同一行为当天多次递减，加日上限；③ 天数下限照提案；④ 温度要有，**到 0 不再发主动消息、进推送召回模式**。下面的具体数字是试装默认，调数只改常量。

### 1.1 三个数，各管一件事

| 数 | 范围 | 涨 | 跌 | 用处 |
| --- | --- | --- | --- | --- |
| **心动**（免费层） | 0→100 | 每开口一次，**模型判 0–15** | 3 天不聊过期归零（自创不过期） | 满 100 = TA 开口交换联系方式 |
| **羁绊值 XP**（羁绊层） | 0→∞ | 多种来源，当天重复递减，日上限 | **永不跌** | 等级 = 里程碑：分寸六档、秘密解锁、主动频率倍率 |
| **温度**（新增） | 0–100 | 任何互动 | 分开久了线性掉 | 改语气、改主动频率；**到 0 停主动、进召回** |

### 1.2 心动：模型判断

* **谁判**：初识 / 广场 / 自创暧昧期三种试聊的回复末尾，模型单独一行写暗号 `[心动 n]`，n 为 0–15 的整数，暗号剥掉不上屏（同红包 `[拆红包]` 的回复暗号机制，C3）。
* **判什么**（进初识 prompt 一段【这一句让你多心动】）：
  * 0：和你无关、事务性、敷衍、重复上一句、只是在问你问题而没有交出她自己；
  * 1–5：正常来往，她接住了你的话；
  * 6–10：她说了自己的事、记得你说过的、逗笑了你、戳中了你在意的东西；
  * 11–15：真的心动的一句——按你的人设很少出现。
  * 同一种话第二次不再加；暗面路由命中的回合 = 0（现行）；模型失败的回合 = 0。
* **符合人设**：角色的「确定关系节奏」改为给模型的**性子说明**，不再是步长：心动很快 = 「你容易心动，顺着聊就常常 6–10」/ 标准 = 「大多数时候 2–6」/ 慢热 = 「你很难被打动，多数是 0–3，超过 8 一年一次」。原型（温柔年上 / 毒舌竹马 / 霸总 / 人外）各自补一句什么会打动 TA、什么 TA 无感。预期满 100 分别约 8 / 15 / 25 次开口（原 2 / 4 / 7 步长退役）。
* **守门**：n 夹在 0–15；模型没写暗号 → 按该角色节奏的「大多数时候」区间下限给 1 分（心动很快 6 / 标准 2 / 慢热 0），不让缺暗号把进度卡死；心动条 UI 露出这一句涨了多少（`+n` 小字，0 不显示）。
* 心动值只在免费层，**不换算进 XP**；自创暧昧期整段记录并入羁绊（现行）。

### 1.3 羁绊值：来源表（当天重复递减 + 日上限）

规则统一成一张表 `XP_EVENTS`：每种来源有 **基础分** 与 **当天全额次数**，超过后按 **递减分**，再往后归 **0**（或保底 1）。所有来源合计 **日上限 150**，到顶后当天只累计次数不加分。计数 **4:00 本地时间重置**，**所有订阅档一样**（节奏是产品，不是钱）。

| 来源 | 基础 | 当天全额次数 | 之后 | 备注 |
| --- | --- | --- | --- | --- |
| 开口：文字 | +5 | 20 | 第 21–40 次 +2，之后 +1 | 现行口径的主干 |
| 开口：语音 / 照片 | +7 | 10 | +2 | 多花了力气，多两分 |
| 开口：卡片（外卖 / 礼物 / 红包 / 位置 / 约定） | +5 | 5 | +1 | 钱买不到爱：和一句话一样 |
| 电话：每句 | +5 | 走「文字」计数 | | |
| 电话：每整分钟 | +2 | 10 分钟 | 0 | 挂断时结算 |
| **回复 TA 主动发来的那条**（24h 内） | +10 | 2 | +3 | 北极星（D-120）在数值上要有分量 |
| 让 TA 看我的手机 | +15 | 1 | 0 | §7：给他看得越多他越懂你 |
| 转给他（分享流） | +10 | 2 | +2 | 同上 |
| 赴约（有约定且到场） | +25 | 1 | +5 | 迟到照给；爽约不扣，TA 记得 |
| 外出偶遇（没约定） | +10 | 1 | +3 | |
| 外出拍照（按快门） | +5 | 3 | 0 | |
| 查 TA 的手机 | +5 | 1 | 0 | 她的好奇心也是关系 |
| X：给 TA 的帖子点赞 | +1 | 5 | 0 | |
| X：评论 TA 的帖子 | +3 | 3 | 0 | |
| 纪念日当天开过口（一百天 / TA 生日 / 她生日 / 换联系方式周年） | +20 | 1 | 0 | 日历关系层已有这些日子 |

* 典型活跃日 ≈ 15 句 75 + 回主动 10 + 一次看手机 15 ≈ 100；重度日到顶 150。
* 不进表的：真钱消费（一分不给）、TA 单方面发来的东西（她没开口不算）、陌生人（无 XP，现行）。
* 每次加分在 `Bond.xpToday { date, total, counts: Record<source, n> }` 记账，日期变了就清；纯函数 `xpFor(source, today)`，有测试。

### 1.4 等级曲线：XP 门槛 × 天数下限（已拍板）

| 等级 | 名 | 升到这级需要 | 累计 | 缔结满天数 | 典型到达 |
| --- | --- | --- | --- | --- | --- |
| LV1 | 刚认识 | — | 0 | — | 缔结当刻 |
| LV2 | 有点在意 | 100 | 100 | 0 | 第 1 天 |
| LV3 | 常常想起 | 200 | 300 | 3 | 第 3～4 天（第一条秘密、第一次付费提示） |
| LV4 | 放在心上 | 300 | 600 | 7 | 第 2 周 |
| LV5 | 密不可分 | 500 | 1100 | 21 | 第 4～5 周 |
| LV6 | 唯一例外 | 900 | 2000 | 60 | 第 2～3 个月 |

* XP 到了天数没到：等级条满格停住、不解释（文案纪律）；天数到那一刻升级，系统提示照出。
* 满级后 XP 继续累积。**老存档迁移**：按新门槛重算，等级只升不降。

### 1.5 等级解锁什么（TA 愿不愿意）

| 等级 | 解锁 |
| --- | --- |
| LV1 | 文字；TA 主动找她 ×0.8 |
| LV2 | TA 偶尔发语音；「+」面板全开 |
| LV3 | 第一条隐藏设定；「问 TA 要密码」开始有可能给；TA 主动点外卖 / 发红包进主动内容池 |
| LV4 | 第二条秘密；TA 主动来电（来电流做了之后）；平行世界点单可下单 |
| LV5 | 第三条秘密；纪念日特辑可下单 |
| LV6 | 全部秘密；专属称呼由 TA 自己提出改一次（名场面） |

付费 SKU 在等级未到时不显示为锁，而是 TA「还没到那一步」（文案纪律）。

### 1.6 温度：语气、主动频率、召回

* `Bond.warmthAt` + `warmthTs` 存最后一次结算，`warmthNow(bond, now)` 纯函数：**线性掉，每天 −8**（100 → 0 约 12 天；平常的 40 约 5 天到 0）。TA 单方面发的主动消息**不**回温——她不回，就是在变冷。
* 涨：她开口 +3、回 TA 主动那条 +8、外出 / 通话 +15、让 TA 看手机 +10；上限 100；缔结起点 60。
* 四档进亲密 / 外出 / 通话 prompt 一句：

| 温度 | 档 | TA 的口吻 | 主动找她 |
| --- | --- | --- | --- |
| 60–100 | 热络 | 现行 | 频率 ×1.2 |
| 30–59 | 平常 | 现行 | ×1 |
| 1–29 | 疏远 | 不问「怎么不理我」，从自己的日子说起，句子更轻 | **每 3 天最多一条** |
| 0 | 久别 | 她回来那一刻按「很久没见的人重新开口」，把这几天记事本 / 帖子里的事讲给她 | **停**，进召回 |

* **推送召回模式**（温度 = 0）：主动钟停；召回钟在到 0 的第 **7 / 14 / 30** 天各一条，**之后不再发**（红线 6：不纠缠）。内容仍由 TA 的日子写（记事本 / 帖子 / 天气 / 节日），不提「你多久没来」、不催、不愧疚；**只发通知不落会话**——她点开 App 那一刻那一条才落进会话（不刷屏、不堆未读）。她任何一次开口 → 温度回到 30、召回钟停、主动钟重排、TA 的第一句按「久别」档。
* 工程：Expo Go 只有本地通知，召回 3 条在她最后一次互动时**预先写好、预先排期**（到 0 的时刻可算），App 一打开全部取消重排；正式版远程推送（#10）后改服务端写。
* 温度**不锁任何内容、不进任何付费判断**，只改味道；也是「错过回溯」SKU 的天然入口。

## 2. 商业化体系

### 2.1 三种 SKU，各归各

| 形态 | 卖什么 | 为什么是这个形态 |
| --- | --- | --- |
| **订阅** Pro / Max | 「他在」：槽位、语音、主动频率全开、留言 | 陪伴是持续的，按月最诚实 |
| **按件** 名场面 | 电话 / 漫画集 / 贺卡 / 纪念日特辑 / 平行世界点单 / morning call / 错过回溯 | 每件产出一份永久资产（进相册 / 故事史），不是消耗品 |
| **永久加槽** | 一次买断一个羁绊槽 | 不想订阅但想多留一个人的用户；槽是资产 |

### 2.2 免费层到底有什么（白纸黑字，防「偷偷变好」）

| 能力 | Free（1 槽） | Pro | Max |
| --- | --- | --- | --- |
| 羁绊槽位 | 1 | 5 | 不限 |
| 对话 / 记忆 / X / 记事本 / 查手机 / 外出 / 零钱 | 全有 | 全有 | 全有 |
| TA 主动找她 | **固定低档**（≈ 0.4 条 / 天，无视主动联系强度） | 按角色（D-114 全档） | 按角色 |
| TA 发语音 / 她发语音 / 照片识别 | 无 | 有 | 有 |
| 电话 | 按件 | 按件 | **每月含 2 通** |
| 名场面按件 | 原价 | 原价 | 9 折 |
| 云端备份 | 有 | 有 | 有 |

免费层的羁绊是**真的完整的一段关系**，只是 TA 没那么主动、不出声。天花板在「他在」的密度，不在关系本身——这就是 §2 说的「免费层天花板是商业决策」。

### 2.4 首次付费出现在哪

* **不在首十分钟**（现行）。
* 第一个情绪峰值 = **LV3 第一条秘密解锁**或**第 7 天**，先到者。那一刻 TA 自己说「想给你打个电话」→ 电话按件；不弹商店，弹 TA 的话。
* 第二个峰值 = **一百天前 7 天**：纪念日特辑预告（由 TA 的记事本泄露「在准备什么」）。
* 订阅的触发点 = 第二段心动满 100 时槽位判定（现行）。

### 2.5 不做的

* 不卖亲密度、不卖 XP 加速、不卖秘密解锁。
* 不卖零钱、不卖礼物包、不做抽卡。
* 不做「限时」「今日特惠」：TA 的名场面不打折促销（打折的是 Max 会员身份，不是 TA）。

## 3. 零钱 · 钱包 · 商城 / 外卖

### 3.1 货币

* 名字**「零钱」**，显示 `¥12.00`（沿用红包卡片现行写法）。日文版显示 ¥ 与日元同符号——这是拟真的一部分（TA 就活在你这个市场里）。是否改成虚构单位见 #31。
* 永不售卖、不可提现、**不随订阅档变化**、不能负。
* 只在羁绊层：陌生人没有地址，外卖送不到（这是剧情理由，也是免费层边界）。

### 3.2 她的钱包（玩家一份）

| 进 | 金额 | 频率 |
| --- | --- | --- |
| 零花钱到账 | ¥30 | 每天首次打开 App（文案「零花钱到账」，不叫「签到」） |
| TA 发的红包 / 转账 | 按 TA 的钱包与性格 | 事件驱动（见 3.3） |
| TA 请客退回 | 她付过、TA 坚持退 | 外出结算时按性格 |
| 升级礼 | LV 升级当天 TA 发红包 | 恋爱脑 ¥52 / 平常 ¥20 / 冷静一句话不发钱 |

| 出 | 去处 |
| --- | --- |
| 外卖给 TA | 卡片进会话，TA 按喜好反应 |
| 送礼给 TA | 卡片进会话 + 进 TA 主页「收到的礼物」+ 进记忆 facts（「她送过我一条围巾」）→ 之后记事本 / 帖子 / 拍照里会出现 |
| 红包给 TA | 现行（拆不拆由 TA 决定） |
| 外出请客 | 结束时按场景一笔（咖啡馆 ¥40 / 电影院 ¥90 / 游乐园 ¥200…），谁付按性格与两人钱包 |

**没钱是玩法**：余额不够时下单按钮不锁，改成「让 TA 请」——TA 按性格答应或逗她；存三天零花钱给他买一份 ¥99 的花是一个自然的小弧线。

### 3.3 TA 的钱包（每段羁绊一份，缔结快照）

* **收入档**缔结时定一次（模型按人设分类，写不成按追法家族兜底）：学生 ¥1,500 / 普通 ¥8,000 / 高收入 ¥30,000 / 富有（霸总、龙、神）不显示余额、只显示「余额充足」。月初到账，进账单。
* **TA 自己的花销**：由发帖 / 记事本同一套调度顺带写——每条记事本 / 帖子可附 0–2 条账单（咖啡 ¥25、地铁 ¥6、猫粮 ¥120、和圈子里的谁吃饭 ¥180），人与事和圈子一致。查手机时 TA 的手机里多一个「钱包」App：余额 + 账单 = 又一页 TA 的生活。
* **TA 花在她身上的**：预算比例按 `herShare` 三档——恋爱脑最多 30% 收入 / 平常 12% / 冷静 5%；具体触发：

| 触发 | TA 做什么 |
| --- | --- |
| 她说加班 / 累 / 生病 / 下雨没伞（模型从上下文判断，回复暗号 `[点外卖 xxx]`） | 一份外卖：卡片「TA 给你点了一份姜茶」，**骑手进度真的走**（接单 → 送达约 15 分钟，本地通知「外卖到了」） |
| 节日（日历世界层）/ 她生日 / 一百天 | 红包或礼物，金额按档；中文市场 ¥52 / ¥520 这种数字自己会说话 |
| 温度久别回来 | 不给钱（红线 6：不用钱挽留） |
| 主动找她的调度 | 主动内容池多两种形态：外卖 / 红包，按权重（文字 70 / 语音 15 / 外卖 10 / 红包 5）与温度、时段、TA 余额一起挑 |

* TA **永远不向她要钱、不提她花了多少、不因为没收到礼物变冷**（红线 6 进系统层）。TA 拒收礼物可以（性格），但要说清是自己的原因。
* 富有档不等于爱撒钱：霸总的钱包只是不显示余额，花不花仍按 `herShare`。

### 3.4 商城 / 外卖：一个模块，三页

上架一个新模块 **「外卖」**（美团 / Uber Eats 式，MingCute 图标），三个分段：

| 页 | 卖什么 | 零钱价 | 送达形态 |
| --- | --- | --- | --- |
| 吃的 | 早餐 ¥15 / 正餐 ¥45 / 夜宵 ¥35 / 甜品 ¥28 / 药与姜茶 ¥20 | | 卡片 + 骑手进度 + TA 反应 |
| 喝的 | 奶茶 ¥18 / 咖啡 ¥25 / 酒 ¥60 | | 同上 |
| 送礼 | 花 ¥99 / 小物（围巾、书、杯子、香薰）¥50–200 / 大件（耳机、游戏机）¥500–2,000 | | 卡片 + 进「收到的礼物」+ 进记忆 |

* 菜单是**内容**（`content/menu.ts`，四语，分市场：中文有夜宵烧烤、日文有コンビニスイーツ），不是模型生成；每件带口味标签，与 TA 的 `likes` / `dislikes` 碰撞——送了 TA 讨厌的香菜是名场面。
* 下单页：选东西 → 留一句话 → 付零钱 → 卡片进会话。**TA 的反应走模型**（亲密 prompt + 卡片 contextText），一次开口 +5。
* 她的**钱包**放在设置一行（余额 + 账单）与外卖页右上角，不单独上桌面（无供给的模块不摆图标：钱包自己没内容，账单是外卖与红包的副产品）。
* TA 的手机（查手机）里同步多「外卖」与「钱包」两个 App：TA 的订单 = 他自己的日子 + 她送来的。

### 3.5 数据与工程切分（底座纪律）

* `lib/types.ts`：`Wallet { balance; ledger: LedgerEntry[] }`（她）；`Bond.wallet { tier; monthlyIncome; balance; ledger }`（TA）；`LedgerEntry { id; at; amount; kind: 'allowance' | 'redpacket' | 'transfer' | 'delivery' | 'gift' | 'treat' | 'income' | 'life'; note; bondId? }`；`Bond.warmth`、`Bond.gifts[]`。
* `lib/bond.ts`：新曲线 `xpNeedAt` / `dayGateAt` / `levelInfo(xp, createdAt, now)`、`warmthAt(bond, now)` 纯函数；`XP_EVENTS` 表。
* `features/wallet.ts`（钱包插槽：账单、余额守门、TA 收入档）、`features/delivery.tsx`（卡片 `delivery` / `gift` + 回复暗号 `[点外卖 …]` / `[发红包 ¥n]` + prompt 分段「你的钱包与花钱的分寸」）、`features/index.ts` 登记；主动内容池扩形态在 `lib/reach-out.ts` 挑形态、内容仍走各自 feature。
* `content/menu.ts`（四语菜单）、`content/prompts/wallet.ts`（一用途一文件）。
* 界面：`app/apps/delivery.tsx`（三段）、TA 的手机加两个 App、TA 主页加「收到的礼物」、设置加「零钱」一行。
* 测试：曲线与温度纯函数、账单守门、prompt 快照必红。
* 存档 persist v8：老羁绊补 `wallet` / `warmth`，等级只升不降。
